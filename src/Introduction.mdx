# react-compound-ui

My personal React component library: small, accessible components built as **compound components** so each piece can be arranged freely.

```tsx
import { Card, Button } from '@laugostini20-byte/react-compound-ui';
import '@laugostini20-byte/react-compound-ui/styles.css';

<Card>
  <Card.Header><Card.Title>Hello</Card.Title></Card.Header>
  <Card.Body>Composable pieces.</Card.Body>
  <Card.Footer><Button>Save</Button></Card.Footer>
</Card>
```

## Theming

The default **Lagoon** palette pairs a deep teal primary (`#0f766e`) with a coral accent (`#f97360`).

Every color, radius and spacing value is a CSS variable prefixed with `--rcu-`. Override them in your app to re-theme:

```css
:root {
  --rcu-color-primary: #0ea5e9;
  --rcu-radius-md: 4px;
}
```

Add `data-theme="dark"` to any ancestor for dark mode.
